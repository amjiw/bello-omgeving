# Boeken bij de cursus

## Get Started with MicroPython on Raspberry Pi Pico (`pico.pdf`)

Gareth Halfacree & Ben Everard, *Get Started with MicroPython on Raspberry Pi Pico*,
eerste editie, Raspberry Pi Trading Ltd (Raspberry Pi Press), Cambridge, 2021. ISBN 978-1-912047-86-4.
Digitale versie v11 (`RPi_PiPico_Digital_v11.pdf`), ongewijzigd overgenomen.

Licentie: **Creative Commons Attribution-NonCommercial-ShareAlike 3.0 Unported (CC BY-NC-SA 3.0)**,
zoals vermeld op pagina 4 van het boek ("except where otherwise noted"):
https://creativecommons.org/licenses/by-nc-sa/3.0/

Het bestand staat hier voor onderwijsgebruik bij de cursus *Programmeren & Mechatronica* (NHL Stenden,
Werktuigbouwkunde), niet-commercieel, met bronvermelding. Raspberry Pi is niet betrokken bij deze cursus.
De uitgever biedt het boek zelf niet meer gratis aan; deze kopie komt uit het Internet Archive
(snapshot van 7 januari 2025 van de oorspronkelijke downloadlink van hackspace.raspberrypi.com).
De tweede editie (2024, Pico 2) is te koop via Raspberry Pi Press.

Vaste link: https://amjiw.github.io/bello-omgeving/boeken/pico.pdf (hoofdstukken via `#page=`, bijvoorbeeld
`#page=8` voor hoofdstuk 1, `#page=128` voor Appendix B).
