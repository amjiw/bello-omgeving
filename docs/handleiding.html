De Bello-omgeving op je eigen laptop

Installeren, starten, werken, bijwerken, en wat je doet als het niet werkt.

handleiding bij versie 2026.11.04h

1. Wat je krijgt

Alles voor de cursus zit in één pakket dat op je eigen laptop draait: de simulator met Bello, een code-editor, de AI-tutor, een MQTT-broker en een Pico-emulator. Het pakket draait in Docker-containers, een soort afgesloten kastje op je laptop. Jij werkt in de browser en hoeft verder niets te installeren, ook geen Python of Webots.

Thuis werkt het zonder wifi. Alleen de AI-tutor (het taalmodel in de cloud) en de eerste keer laden van het 3D-beeld hebben internet nodig.

3. Docker Desktop installeren

Eenmalig, ongeveer een kwartier. Dit is de enige installatie.

Windows

  1. Download Docker Desktop voor Windows van docker.com en start het installatieprogramma.
  2. Laat het vinkje Use WSL 2 instead of Hyper-V aan staan. Docker regelt WSL 2 zelf.
  3. Herstart als Windows daarom vraagt. Soms moet dat twee keer.
  4. Start Docker Desktop via het startmenu. Accepteer de voorwaarden (gratis voor onderwijs en persoonlijk gebruik). Een account aanmaken is niet nodig: kies Skip of Continue without signing in.
  5. Wacht tot het walvis-icoon rechtsonder in de taakbalk rustig staat. Dan is Docker klaar.

macOS en Linux

Mac: download de versie die bij je processor past (Apple Silicon of Intel) en sleep de app naar Programma's. Linux: Docker Desktop of Docker Engine met het compose-plugin; controleer met docker compose version.

Docker Desktop hoeft niet bij het opstarten van je laptop mee te starten. Zet dat uit onder Settings → General → Start Docker Desktop when you sign in als je laptop traag wordt. Start het dan zelf voordat je met Bello begint.

4. Starten

  1. Download bello-omgeving.zip (altijd de nieuwste versie; de zip is klein) en pak hem uit op een vaste plek, bijvoorbeeld C:\dev\bello-omgeving (maak de map C:\dev aan als die er nog niet is). Verplaats de map daarna niet meer: de mapnaam bepaalt waar Docker je code bewaart.
  2. Zorg dat Docker Desktop draait (walvis-icoon in de taakbalk).
  3. Open in de Verkenner de uitgepakte map bello-omgeving. Daar staan de knoppen: starten.cmd, stoppen.cmd, bijwerken.cmd en diagnose.cmd. Dubbelklik op starten.cmd. Er opent een zwart venster dat de voortgang laat zien; de eerste keer haalt hij ongeveer 3,5 GB op en dat duurt een paar minuten tot een kwartier. Daarna start hij in een halve minuut.
  4. De browser opent http://localhost:8000. Zie je nog niets, wacht dan een halve minuut en ververs: de simulator start als laatste.

Mac en Linux hebben geen .cmd-bestanden. Open een terminal in de uitgepakte map:

cp .env.example .env
docker compose --profile pico up -d       # starten
docker compose --profile pico stop        # stoppen
docker compose --profile pico pull && docker compose --profile pico up -d   # bijwerken

5. De startpagina

Op localhost:8000 staan vier tegels. Elke tegel opent een eigen tabblad.

1. Bello in 3DHet beeld van de simulatie. Met de muis draai en zoom je. Onder het beeld staat de console: wat Bello zegt en de foutmeldingen uit je code. De knop met de luidspreker zet het blafgeluid aan; browsers spelen pas geluid na een klik.
2. Je codeDe editor (VS Code in de browser) met mijn_code.py. Hier werk je.
3. AI-tutorHints bij fouten en begrippen, geen uitwerkingen. Werkt vanaf week 3 met je eigen sleutel.
4. Pico in de browser (Velxio)Een nagebootste Raspberry Pi Pico met LED-ogen, noodstop en oefenpoot, al bedraad.

Onderaan de startpagina staan het versienummer en de lijst wat is er nieuw.

6. Werken in de editor

Tegel 2 opent de map met mijn_code.py. Dat is jouw bestand: alles wat je Bello laat doen, schrijf je hier. Alleen dit bestand is van jou; de andere bestanden in de map (zoals max_api.py, max_speels.py en de map pico) horen bij de cursus en worden bij elke start van de omgeving teruggezet. Een wijziging daarin raak je dus kwijt, en Run in Webots doet er ook niets mee: die draait alleen mijn_code.py. Elk programma begint met:

from max_speels import Bello
bello = Bello()

bello.zwaai()

De editor kent Python: rode kringels bij fouten en aanvulling als je bello. typt. Wat Bello zegt (bello.zeg) en de foutmeldingen zie je in de console onder het 3D-beeld. Een rode regel met Traceback is een fout in je code; de laatste regel zegt wat er mis is en bij welk regelnummer.

Houd één browservenster met het 3D-beeld open naast de editor. Twee schermen of de vensters naast elkaar werkt het prettigst.

7. Pico in de browser

Tegel 4 opent Velxio met het Bello-project: een Raspberry Pi Pico met LED-ogen op GP14 en GP15, een noodstop op GP16, twee servo's van de oefenpoot op GP12 en GP13 en een MPU6050 op I2C0. De bedrading staat al klaar; main.py bevat een voorbeeldprogramma.

  1. Druk op Run. De LED-ogen gaan aan en de seriële monitor toont regels als CMD:blaf 3.
  2. Elke CMD:-regel wordt een beweging van Bello in het 3D-tabblad.
  3. Druk op Stop om het programma te stoppen. Een nieuwe Run begint met Bello op de startpositie.

Voorwaarde: Bello luistert pas als je eigen mijn_code.py klaar is. In de console staat dan [Bello/pico] klaar. Een programma dat eindeloos doorloopt houdt Bello bezet. Dit luisteren gebeurt vanzelf, je hoeft er niets voor in te stellen; vanaf week 6 stuurt een echte Pico W op hetzelfde wifi op dezelfde manier commando's.

8. De AI-tutor

De tutor geeft hints, geen antwoorden. Hij leest je mijn_code.py en de laatste foutmelding mee, zoekt in het cursusmateriaal en wordt per vraag in hetzelfde gesprek iets concreter: eerst een vraag terug, dan het begrip met de bron, dan een voorbeeld in een andere situatie, dan de regel waar het misgaat. De uitwerking schrijf je zelf. Aandringen helpt niet; dat is de afspraak, geen storing.

De tutor werkt vanaf de workshop in week 3 met een gratis sleutel van Groq, een dienst die open taalmodellen draait. Er is geen creditcard of betaling voor nodig. Zo kom je eraan:

Een Groq-sleutel aanmaken

  1. Ga naar console.groq.com en kies Sign up. Inloggen kan met je schoolmail, een Google-account of een GitHub-account. Bevestig de e-mail als daarom gevraagd wordt.
  2. Klik in het menu links op API Keys en daarna op Create API Key. Geef hem een naam, bijvoorbeeld bello.
  3. Kopieer de sleutel meteen (hij begint met gsk_). Groq laat hem maar één keer zien; kwijt is kwijt, dan maak je gewoon een nieuwe.
  4. Open in je map bello-omgeving het bestand .env met Kladblok (rechtsklik → Openen met) en plak de sleutel achter het gelijkteken, zonder spaties of aanhalingstekens: 
    GROQ_API_KEY=gsk_...
    Sla het bestand op.
  5. Dubbelklik op stoppen.cmd en daarna op starten.cmd. De omgeving leest .env alleen bij het starten; de pagina verversen is niet genoeg. In de statusregel van het Tutor-tabblad staat nu taalmodel: groq → lokaal.

Zie je in de Verkenner geen .env maar alleen .env.example? Dan is starten.cmd nog nooit gedraaid; die maakt .env aan. Bestanden die met een punt beginnen zijn soms verborgen: zet in de Verkenner onder Beeld de optie Verborgen items aan.

De gratis laag van Groq heeft een limiet per sleutel (in de orde van 30 vragen per minuut en 1000 per dag), ruim genoeg voor een lesdag. Groq bewaart je vragen standaard niet; de servers staan in de Verenigde Staten. Zet er dus geen persoonsgegevens in.

Je vindt de tutor op twee plekken, en het is dezelfde: tegel 3, en in de editor via Ctrl+L. Alles komt in een logboek op je eigen laptop (knop logboek, via tegel 3): per vraag de tijd, je vraag, het soort hint en het fouttype, zonder namen. De docent mag er bij de assessment naar vragen. Dit logboek is iets anders dan de kennismap /werk/tutor/kennis, waarin de bronnen staan die de tutor mag gebruiken.

Je sleutel is persoonlijk. Nooit delen, nooit in je code zetten, nooit in een verslag plakken. Tot week 3 mag .env leeg blijven; de tutor meldt dan netjes dat er geen taalmodel is.

9. Stoppen, bijwerken, terugdraaien

WatHoe
Stoppenstoppen.cmd, of de container stoppen in Docker Desktop. Je code blijft bewaard.
Nieuwe versie van de docentGaat vanzelf: starten.cmd kijkt bij elke start of er een nieuwe versie is en haalt alleen het verschil op (meestal enkele megabytes). Laat je de omgeving dagen draaien, dan meldt de startpagina een nieuwe versie; dan stoppen.cmd en starten.cmd, of bijwerken.cmd (haalt ook nieuwe instellingen op). Je eigen mijn_code.py blijft altijd staan.
Welke versie heb ik?Onderaan de startpagina. Dit is de eerste vraag die de docent stelt bij een storing.
TerugdraaienZet in .env de regel BELLO_VERSIE=2026.11.04 (de oude datum) en draai bijwerken.cmd. Terug naar nieuw: BELLO_VERSIE=latest.
Lokale AI aan of uitai_lokaal_aan.cmd / ai_lokaal_uit.cmd. Alleen zinvol met 16 GB werkgeheugen.

Je code staat in een Docker-volume met de naam max_werk. Een nieuwe versie van de omgeving raakt dat volume niet. Het verdwijnt alleen met docker compose down -v, en dat commando typ je dus nooit zomaar.

Kom je er niet uit: dubbelklik op diagnose.cmd. Die maakt een zip met je versie, de logboeken, de console en je mijn_code.py (zonder je sleutels). Stuur die via Teams naar de docent en schrijf erbij wat je deed en wat je verwachtte.

11. Veelgestelde vragen

Waar staat mijn code, en hoe maak ik er een kopie van?

In het Docker-volume, niet in een gewone map. Een kopie maak je in de editor: rechtsklik op mijn_code.py in de verkenner links en kies Download. Of selecteer alles (Ctrl+A), kopieer, en plak het in een bestand op je eigen schijf. Doe dat aan het eind van elke lesdag.

Mag ik de map verplaatsen of hernoemen?

Liever niet. De naam van de map bepaalt de naam van de containers en het volume. Verplaats je hem toch, maak dan eerst een kopie van je code.

Hoe krijg ik de schijfruimte terug na de cursus?

Eerst je code veiligstellen. Dan in de map: docker compose --profile pico down -v en daarna docker image prune -a. Docker Desktop zelf verwijder je via Windows-instellingen.

Kan ik het ook zonder Docker doen?

Ja, met de losse bundel (Webots en Thonny, alleen Windows), maar dan zonder tutor en zonder Pico-emulator. Vraag de docent.

Moet Docker Desktop altijd aan staan?

Alleen als je met Bello werkt. Sluit je het, dan stopt alles; je code blijft bewaard.
